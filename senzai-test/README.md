# 宣材写真 AI生成 検証パイプライン

白ホリスタジオの宣材写真をAIで生成し、品質を目視評価するためのツールです。

---

## 必要なもの（事前準備）

### 1. Python 3.11 以上を確認する

ターミナルで以下を実行：

```bash
python3 --version
```

`Python 3.11.x` 以上と表示されれば OK。  
表示されない場合は [https://www.python.org/downloads/](https://www.python.org/downloads/) からインストールしてください。

### 2. Replicate の API キーを取得する

1. [https://replicate.com](https://replicate.com) でアカウントを作成
2. 右上のアイコン → **API tokens** → **Create token**
3. 以下をターミナルに貼り付けて実行（`r8_xxxx` の部分を自分のキーに変える）：

```bash
export REPLICATE_API_TOKEN=r8_xxxx...あなたのキー...
```

> **毎回ターミナルを開くたびに設定が必要です。**  
> 面倒な場合は `~/.zshrc`（Mac）の末尾に上の行を追加してください。

```bash
cd senzai-test

```

## 実行手順（毎回）

### ステップ 1：自撮りを入れる

`input/selfies/` フォルダに自撮り写真（JPEG/PNG/WEBP）を入れてください。

**良い写真の条件：**
- 正面〜斜め 45 度
- 明るい場所
- 顔がはっきり写っている
- マスク・サングラス・強い加工は NG

### ステップ 2：コマンド 1 行で実行

```bash
python generate.py
```

これだけです。  
自動で画像生成が始まり、完了するとブラウザでレポートが開きます。

### ステップ 3：レポートで評価する

ブラウザに表示された `report.html` で：

| 評価項目 | 操作方法 |
|---------|---------|
| 本人忠実度 | ★1〜5 をクリック |
| 破綻チェック | 気になる部分のチェックボックスをオン |
| メモ | テキスト欄に自由記入 |
| 結果を保存 | ページ下部の「評価データをJSONで保存」ボタン |

## 出力ファイルの場所

```
output/
└── 20250612_143022/         ← 実行日時のフォルダ
    ├── report.html          ← 評価レポート（自動で開く）
    ├── run_log.json         ← 実行ログ（モデル・時間・コスト）
    ├── src_selfie01.jpg     ← 元の自撮り（レポート表示用コピー）
    ├── selfie01_s42.png     ← 生成画像（seed=42）
    ├── selfie01_s1337.png   ← 生成画像（seed=1337）
    ├── selfie01_s7777.png   ← 生成画像（seed=7777）
    └── selfie01_s31415.png  ← 生成画像（seed=31415）
```

| ケース | 費用 |
|-------|------|

---

## 合格ライン（評価の目安）

| 項目 | 合格基準 |
|-----|---------|
| 本人忠実度 | ★4 以上が生成枚数の 50% 以上 |
| 破綻ゼロ率 | 全項目チェックなしの画像が 30% 以上 |
| 背景 | 完全な白飛びのないクリーンな白ホリ |
| 原価 | 1 枚あたり 50 円以下 ✅（現状 約 6 円）|

---

## よくあるエラー

| エラーメッセージ | 対処法 |
|--------------|-------|
| `REPLICATE_API_TOKEN が設定されていません` | `export REPLICATE_API_TOKEN=...` を実行 |
| `input/selfies に画像が見つかりません` | JPEG/PNG/WEBP ファイルを `input/selfies/` に入れる |
| API エラー（自動リトライ後も失敗） | 少し待ってから再実行。Replicate のステータスページを確認 |
