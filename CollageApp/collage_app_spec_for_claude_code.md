## 1. プロダクト定義

### 1.1 一言定義
**複数写真（2〜6枚）を美しい余白で1枚の"作品"にする、3タップ完結のコラージュアプリ。**

### 1.2 ポジショニング
- Inset（単写真×多重フレーム）とは非競合。「複数写真×余白コラージュ」の空白地帯を取る
- Unfold（テンプレ探しが必要・サブスク）/ PicCollage（装飾過多）に対し、「デフォルトが既に美しい」引き算の設計で差別化
- 世界観の参照点: Instagram @withgar のような、写真家のギャラリー的レイアウト（縦積み・格子・広い余白・オフホワイト背景）

### 1.3 ターゲット
- カメラ愛好家・フォトグラファー（Insetユーザーと同一クラスタ）
- Instagramで統一感あるフィードを作りたい層

### 1.4 マネタイズ
- 基本機能: 完全無料
- 課金: プリセットパック（非消耗型IAP、StoreKit 2）
  - 例: 「Gallery Pack」「Film Pack」「Editorial Pack」各¥480
  - プリセット = レイアウト＋余白色＋フレーム幅の組み合わせ
- サブスクは採用しない（買い切りの安心感を訴求）

## 2. UX仕様：「3タップで作品」

### 2.1 コアフロー（必ずこの体験を守る）
1. **タップ1**: 起動直後にPhotosPickerが開く。写真を2〜6枚選択（選んだ順＝配置順）
2. **タップ2**: 選択と同時にレイアウトが自動生成され、プレビュー表示。横スワイプでレイアウト候補を切替（探させない、提示する）
3. **タップ3**: 保存ボタン → フル解像度でフォトライブラリへ書き出し

**設計原則: デフォルトで美しい。調整は「したい人だけ」が触る。**

### 2.2 画面構成（2画面のみ）

#### 画面A: ホーム（最小）
- 中央に「＋ 写真を選ぶ」ボタン1つ
- 下部に保存済みプリセット一覧（横スクロール、Insetレビューの要望「ホームからプリセット選択」を先回りで実装）
- 設定はギアアイコン1つ（書き出し画質・EXIF保持ON/OFFのみ）

#### 画面B: エディタ
- 上部: プレビュー（キャンバス）
- 中部: レイアウト候補の横スワイプカルーセル（ドット表示）
- 下部: 調整パネル（3項目のみ、Insetと同じ引き算思想）
  1. **余白**: スライダー（0〜15%）＋色（白/黒/オフホワイト#F5F2ED/スポイト/カラーピッカー）
  2. **比率**: 1:1 / 4:5 / 3:2 / 9:16 / 4:3（セグメント切替。写真はトリミングせずフィット）
  3. **間隔**: 写真同士のガター幅スライダー
- 右上: 保存 / プリセット登録
- Undo/Redo対応（Insetが後追いで実装した機能。最初から入れる）

### 2.3 レイアウトエンジン（MVPは6種）
選択枚数に応じて自動で候補を出す。

| 枚数 | レイアウト候補 |
|---|---|
| 2枚 | 縦積み / 横並び / 大小（メイン＋サブ） |
| 3枚 | 縦積み / 1大＋2小 / 横3列 |
| 4枚 | 2×2 / 縦積み / 1大＋3小 |
| 5〜6枚 | グリッド / 縦積みストリップ |

- 各写真は元のアスペクト比を保持（トリミングなし）。セル内にアスペクトフィット
- 縦積み時は幅を揃え、高さは写真比率に従う（withgar型の肝）

## 3. 技術仕様

### 3.1 スタック
- **言語/UI**: Swift 5.10+ / SwiftUI（iOS 17.0+ ターゲット）
- **写真選択**: PhotosUI `PhotosPicker`（フォトライブラリ全権限は要求しない。選択写真のみアクセス）
- **課金**: StoreKit 2（非消耗型）
- **永続化**: プリセットはSwiftData or JSONファイル（軽量なのでJSONで可）
- **外部依存**: ゼロを目標（SPMパッケージ不使用。Inset同様の軽量アプリ 3〜5MB を目指す）

### 3.2 レンダリングパイプライン（最重要・品質の差別化点）
Insetのレビューに「空のグラデーションでトーンジャンプ（バンディング）が出る」という弱点報告あり。ここで勝つ。

- **プレビュー**: 表示用は長辺2048pxにダウンサンプルした画像で描画（メモリ対策）
- **書き出し**: 元画像フル解像度を`CGContext`で合成
  - カラースペース: 元画像のカラースペースを維持（Display P3対応）
  - ビット深度: 元画像が10bit以上なら16bit contextで合成（バンディング防止）
  - 出力: HEIC（デフォルト）/ JPEG最高画質（設定で切替）
- **EXIF**: 書き出し時に1枚目の写真のEXIF（撮影日時・カメラ・レンズ）を`CGImageDestination`でコピー保持（設定でON/OFF）
- メモリ: 6枚×フル解像度の同時展開を避け、書き出し時は1枚ずつ順次合成

### 3.3 プロジェクト構成（Claude Codeへの指示）
```
CollageApp/
├── App/
│   └── CollageApp.swift
├── Models/
│   ├── CollageLayout.swift      // レイアウト定義（enum + セル矩形計算）
│   ├── CanvasSpec.swift         // 比率・余白・ガター・背景色
│   └── Preset.swift             // Codable
├── ViewModels/
│   └── EditorViewModel.swift    // @Observable。Undo/Redoスタック含む
├── Views/
│   ├── HomeView.swift
│   ├── EditorView.swift
│   ├── LayoutCarousel.swift
│   └── AdjustPanel.swift
├── Rendering/
│   ├── CollageRenderer.swift    // プレビュー用（downsampled）
│   └── ExportRenderer.swift     // フル解像度CGContext合成 + EXIF
├── Store/
│   └── PresetStore.swift        // StoreKit 2 + プリセット永続化
└── Resources/
```

## 4. 開発Phase（この順で実装・検証）

### Phase 1: コア体験（目標: 1〜2セッション）
- PhotosPickerで2〜6枚選択 → レイアウト自動生成 → プレビュー → 保存（この時点はプレビュー解像度書き出しで可）
- レイアウト6種、比率5種、余白スライダー＋白/黒/オフホワイト
- **検証基準: 起動から保存まで3タップで完了するか**

### Phase 2: 品質（差別化の核）
- ExportRenderer実装（フル解像度・16bit合成・EXIF保持）
- スポイト＋カラーピッカー、ガター調整、Undo/Redo
- **検証基準: 空グラデ写真でバンディングが出ないこと（α7Vの実写で確認）**

### Phase 3: プリセット＋課金
- プリセット保存/呼び出し（ホーム画面に表示）
- StoreKit 2でプリセットパック3種
- 編集途中の状態復元（アプリ再起動時）

### Phase 4: リリース準備
- アプリアイコン・App Storeスクリーンショット（Inset同様、実UIを見せる構成）
- プライバシー: データ収集ゼロで申告（Inset・余白メーカーと同じ訴求点）

---

## 5. 非スコープ（MVPでは作らない）

- フィルター・色編集（世界観がブレる。写真は撮って出し/現像済み前提）
- テキスト・ステッカー（Phase 5以降で「フレーム部にEXIF文字入れ」のみ検討。Insetレビューで要望多）
- 動画対応 / Android / iPad最適化 / クラウド同期
