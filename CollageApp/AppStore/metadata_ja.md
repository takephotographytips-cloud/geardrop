## 説明文(4000文字以内)

```
Stackは、写真を美しい余白で1枚にまとめる、写真好きのためのコラージュアプリです。

テンプレートを探し回る必要はありません。写真を選ぶと同時に美しいレイアウトが出来上がります。起動から保存まで、わずか3タップ。

◆ 3タップで完成
1. 写真を選ぶ(1〜6枚)
2. レイアウトを確認(縦並び/横並びをワンタップ切替)
3. 保存

◆ デフォルトで美しい
・写真展のギャラリーのような、端正な余白と均等な並び
・余白は0〜15%、写真の間隔も自由に調整
・背景色は白/黒/オフホワイト、スポイトで写真から色を拾うことも
・比率は 1:1 / 4:5 / 3:2 / 9:16 / 4:3(Instagramの投稿・ストーリーズにそのまま)

◆ 直感的な編集
・枠の中で写真をドラッグ移動、ピンチで拡大縮小
・各写真を個別に調整、枠からはみ出た部分は自動でトリミング
・写真を長押しでドラッグ&ドロップして位置を入れ替え
・Undo/Redo対応。アプリを閉じても編集途中から再開できます
・初回起動時のガイドで使い方がすぐわかります

◆ 画質に一切妥協しない
・元画像のフル解像度で書き出し
・10bit以上の写真は16bit処理で合成し、空のグラデーションのトーンジャンプ(バンディング)を防止
・Display P3の色域を維持
・撮影日時・カメラ・レンズのEXIF情報を保持(ON/OFF可)
・HEIC / JPEG最高画質

◆ プリセット
気に入った設定(レイアウト・比率・余白・色・フレーム)は名前を付けて保存。ホームからワンタップで呼び出せます。

◆ Stack Pro(買い切り ¥980)
・プリセット無制限(無料版は3つまで)
・デザインフレーム: フィルム/イエローネガ/シネマ/プリントの4種。グレイン(粒子)でオールドフィルムの質感を再現
・水平・回転補正: 写真ごとに±15°の傾き調整と90°回転。グリッド表示で地平線もぴったり
・お支払いは一度だけ。サブスクリプションはありません

◆ プライバシー
データ収集は一切ありません。写真はあなたの端末の外に出ません。フォトライブラリへのアクセスも「選択した写真」と「保存」のみです。

カメラで撮った写真を、撮ったままの美しさで並べたい。
そんな写真好きのために作りました。
```

## プライバシー(App Privacy の回答)

- **「データを収集しない(Data Not Collected)」で申告**
  - 本アプリは分析SDK・広告SDK・クラッシュレポート等を一切含まない
  - 写真はオンデバイス処理のみ。ネットワーク通信は StoreKit(Apple)のみ
- プライバシーポリシー URL・サポート URL は必須。完成版のサイト一式(3ファイル・日英切替付き)を
  GitHub Pages で公開する:
  - 公開手順: public リポジトリ(例 `stack-site`)を作成 → 以下をアップロード
    - `index.html`(そのまま)… マーケティング URL(任意項目)にも使える
    - `privacy_policy.html` → **`privacy.html` にリネーム**
    - `support.html`(そのまま)
  - Settings → Pages → Branch: main で公開
  - ASC に設定する URL:
    - プライバシーポリシー URL: `https://<ユーザー名>.github.io/stack-site/privacy.html`
    - サポート URL: `https://<ユーザー名>.github.io/stack-site/support.html`
  - リリース後: `index.html` 内の App Store バッジの `href` をストア URL に差し替え
