# 実機QAチェックリスト(提出前の最終確認)

シミュレータでは再現しない問題を洗い出す。実機(できれば普段使いの iPhone)で、
上から順に実施。**✗が出たらその場でスクショ+再現手順をメモして報告**(修正は即日対応)。

## A. コアフロー(3タップ)

- [ ] 初回起動: 写真ピッカーが自動で開く
- [ ] 写真1枚 → 全面1セルで編集できる
- [ ] 写真6枚 → 均等分割される。7枚以上は選択できない(ピッカーの上限)
- [ ] 保存 → 初回に「写真への追加」許可ダイアログ → 許可 → 「保存しました」
- [ ] 写真アプリで保存画像を確認(プレビューと完全に同じ見た目か)

## B. 権限まわり(審査で見られるポイント)

- [ ] 保存の許可を**拒否**した場合 → エラーメッセージが出てクラッシュしない
- [ ] 設定アプリ → Stack → 写真 →「追加のみ」に変更後、保存が成功する
- [ ] 再インストール直後の挙動(権限リセット状態)

## C. 編集機能

- [ ] 各セルで独立してドラッグ/ピンチできる(他セルが動かない)
- [ ] ズーム下限=カバー状態で止まる(背景がのぞかない)、上限5倍
- [ ] 縦⇄横切替で各写真のズーム・位置が引き継がれる
- [ ] 余白0%・間隔0%でも表示が破綻しない
- [ ] Undo/Redo がスライダー・色・比率・フレーム・写真操作すべてに効く
- [ ] スポイト(カラーピッカー左上)で写真から色を拾える

## D. フレーム(Pro)

- [ ] 未購入: フレームに🔒 → タップでペイウォール
- [ ] 4種すべて: プレビューと保存画像の装飾(穴・文字・グレイン)が一致
- [ ] 縦並び・横並び両方でフレームが正しく描かれる
- [ ] 1枚のときのフレーム表示

## E. 課金(実機 + Sandbox)

事前準備: App Store Connect で Sandbox テスターを作成(ユーザーとアクセス → Sandbox)。
実機の 設定 → App Store → サンドボックスアカウント でサインイン。
※実機では Products.storekit は効かない。**ASC に IAP を登録済みであることが前提**

- [ ] ペイウォールに実際の価格「¥980」が表示される(プレースホルダでなく)
- [ ] 購入 → Pro になる(フレーム解放・プリセット4つ目が保存できる)
- [ ] アプリ削除 → 再インストール → 「購入を復元」で Pro が戻る
- [ ] 購入キャンセル(ダイアログで閉じる)してもエラーにならない
- [ ] 機内モードで購入 → 適切にエラー表示

## F. 画質(差別化の核。時間をかける価値あり)

- [ ] α7V(または iPhone)の**空グラデーション写真**で書き出し → 拡大してバンディングが出ないか
- [ ] 写真アプリで保存画像の情報を表示 → **解像度が元写真相当**(2048固定でない)
- [ ] EXIF: 撮影日時・カメラ・レンズが引き継がれている(設定OFFなら消える)
- [ ] 設定で JPEG に切替 → JPEG で保存される
- [ ] 48MP など超高解像度写真×6枚で保存 → クラッシュしない(数秒かかるのは正常)

## G. セッション復元

- [ ] 編集中にアプリをタスクキル → 再起動 → 「前回の編集を再開」で写真・ズーム位置まで復元
- [ ] 復元後に保存まで通る
- [ ] 新しく写真を選ぶと古いセッションが置き換わる

## H. 端末・状況バリエーション(可能な範囲で)

- [ ] iCloud 写真(端末に未ダウンロードの写真)を選択 → 読み込める(少し待つのは正常)
- [ ] ダークモードで全画面の視認性
- [ ] 文字サイズ最大(設定 → 画面表示と明るさ)でレイアウト崩れがないか
- [ ] 通話中バナー・低電力モードでの動作
- [ ] 機内モード(オフライン)でコラージュ作成→保存が通る(課金以外は全機能オフラインで動くはず)
